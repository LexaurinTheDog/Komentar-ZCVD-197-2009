# Komentář k zákonu č. 197/2009 Sb., o certifikaci veřejných dokladů s biometrickými údaji a o změně některých zákonů

Otevřený komentář k zákonu o certifikaci veřejných dokladů s biometrickými údaji — § po §: doslovné znění, výklad, kazuistika, protiargumenty a praktický závěr; pojmy a infrastruktura certifikátů, působnost orgánů, certifikát pravosti, certifikát kontroly pravosti údajů, certifikát přístupu, certifikát oprávnění kontrolního orgánu, zneplatnění certifikátů a změny souvisejících zákonů.

Konsolidované znění: dokument e-Sbírky `SB-2009-00197_2011-05-01`.
